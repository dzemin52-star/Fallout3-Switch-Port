# Fallout 3 – Nintendo Switch Port (Engine Skeleton)

**Это только движок порта. Файлы самой игры не включены.**

Проект демонстрирует, как можно использовать libnx и OpenGL ES 3.2 для создания каркаса порта Fallout 3.

##  Что есть в этом репозитории

- Инициализация графики (EGL + OpenGL ES 3.2)
- Управление памятью под ограничения Switch
- Аудио через audren
- Парсер структуры ESM/BSA (без самих файлов)
- Профилировщик FPS

##  Чего нет
- Файлов игры Fallout 3
- Моделей, текстур, звуков
- Геймплея

## 🔧 Сборка

1. Установи devkitPro
2. Склонируй репозиторий
3. Запусти `make`

Для полноценной работы нужны оригинальные файлы Fallout 3 с ПК (не распространяются).
